#Power BI — Snow Removal Operations Dashboard

This folder contains the Power BI dashboard and supporting files for the Snow Removal Operations Dashboard project.

#Dashboard Purpose

The dashboard analyzes simulated winter snow-removal operations to provide insights into:
•	Snow event activity
•	Service completion
•	Crew performance
•	Operational costs
•	Scheduled versus actual performance
•	Service productivity

Key Analytical Areas

The dashboard is designed to help answer questions such as:
•	How many services were scheduled and completed?
•	What was the completion rate?
•	How many crew hours were used?
•	Which crew completed the most services?
•	What were the operational costs?
•	How did actual service times compare with scheduled times?
•	What was the cost per completed service?

Dataset Disclaimer

This project uses a synthetically generated dataset created for portfolio and demonstration purposes. It does not represent real company, customer, employee, or financial data.

The dashboard is intended to demonstrate the application of Power Query, data modeling, DAX, and Power BI visualization techniques to a realistic winter operations scenario.
